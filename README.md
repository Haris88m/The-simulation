# The Simulation

> **Public research preview. Working title.**

**The Simulation** is an open, model-independent multiplayer possibility engine and live alternate-reality game under development.

The premise is simple:

> No creator, model, or player knows the ending.

The system begins from a versioned evidence baseline, maintains many sampled possible futures, and gives every participant a persistent personal world. A participant may observe, intervene, challenge assumptions, introduce a theory, or introduce any fictional or metaphysical premise. Reality later updates and scores only the claims that were defined as testable forecasts.

## Master rule

**Any premise may be proposed and simulated.**

There are no thematic or ideological restrictions on the possibility space. Scientific integrity is preserved through provenance—not censorship. The system records whether an input is evidence, a hypothesis, an intervention, a fictional premise, or a model-generated proposal.

Unrestricted imagination does not mean unrestricted software execution. Player text is data and is never executed as shell code, SQL, JavaScript, or operating-system instructions.

## What is being built

- A continuously available cloud simulation service.
- Persistent pseudonymous player nodes.
- A private probabilistic world for every player.
- Consensual world forking and merging.
- A shared, evidence-conditioned baseline.
- Provider-neutral access through any AI, local model, custom agent, browser, or command-line client.
- An open structured protocol currently called `WORLD/1`.
- Signed checkpoints, immutable forecast records, and reproducible model versions.
- A live ARG layer generated by real simulation state changes rather than a prewritten ending.

## Public/private repository boundary

This public repository contains the project explanation, public protocol concepts, scientific commitments, transparency design, status, and roadmap.

The authoritative engine, security-sensitive configuration, internal research artifacts, unreviewed coefficients, and deployment implementation remain in a separate private repository while the prototype is being qualified.

| Prospective forecast track | Not yet validated |

The current simulation equations use a synthetic research prior. Outputs must not be presented as verified geopolitical forecasts, policy advice, financial advice, or evidence for metaphysical claims.
