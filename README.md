# The Simulation

This main branch is a publication placeholder. It contains no runnable simulation, dataset or experiment results.

The [public foundation branch](https://github.com/Haris88m/The-simulation/tree/agent/public-foundation-v1) contains a research preview, protocol concepts, scientific-method notes and a static site. Those materials describe the project; they are not a public release of its private simulation engine or evidence of empirical forecast accuracy.

My current research direction is documented at [MEKreflect](https://mekreflect.com/), including [operational AI evaluations](https://mekreflect.com/evaluations/) and the distinction between recorded observations and proposed experiments.

The next release will bring the reviewed inputs, assumptions and reproduction instructions together with the implementation.
