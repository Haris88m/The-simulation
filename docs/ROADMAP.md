# Roadmap

## Phase 0 — Definition and reassessment

- Freeze product concept and master rule.
- Separate possibility and forecast tracks.
- Audit the compact numerical kernel.
- Define provider-neutral protocol and repository boundaries.

## Phase 1 — Working private prototype

- Persistent player nodes.
- Personal and collaborative branches.
- Event-sourced ledger.
- Signed checkpoints and forecast records.
- Fixed-point ensemble simulation.
- Deterministic internal agent orchestration.
- Browser, REST, and encoded packet interfaces.

## Phase 2 — Cloud research alpha

- Managed public API and database.
- Job queue and simulation workers.
- Any-AI adapters.
- Authentication, quotas, recovery, and privacy controls.
- Public transparency commitments.
- Small invited cohort.

## Phase 3 — Empirical model program

- Versioned evidence baseline.
- Domain-specific calibration.
- Historical backtesting.
- Prospective forecast questions.
- Human, model, and hybrid comparisons.
- Published failure and calibration reports.

## Phase 4 — Live multiplayer ARG

- Encoded invitations.
- Generated nodes.
- Cross-world echoes.
- Theory tournaments.
- Consensual civilizations.
- Reality-triggered gates.
- Public research results.

No date is promised until the preceding gate has passed.
