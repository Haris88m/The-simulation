# Master Rule

## Rule zero

> **Any premise may be proposed and simulated.**

The engine does not reject a branch because its premise is political, religious, atheistic, metaphysical, speculative, impossible under current physics, contradictory, unpopular, or unconventional.

Examples of valid premises include:

- God exists.
- God does not exist.
- Reality is simulated.
- Reality is not simulated.
- A new physical law applies.
- Alien contact occurs.
- AI becomes conscious.
- AI progress stops.
- Nation-states disappear.
- An entirely new economic system exists.

## Provenance instead of censorship

Every input carries an epistemic class:

| Class | Meaning |
|---|---|
| `EVIDENCE` | A candidate or verified observation about the shared baseline |
| `HYPOTHESIS` | A claim intended to explain or predict |
| `INTERVENTION` | A deliberate counterfactual change |
| `FICTIONAL_PREMISE` | An assumed condition inside a branch |
| `MODEL_PROPOSAL` | A machine-generated exploration suggestion |

A premise may be simulated without being presented as verified reality.

## Technical boundary

The master rule governs what may be imagined. It does not allow arbitrary code execution, credential theft, data corruption, or bypassing system security. Natural-language input is treated as data and converted into a validated structured event before it reaches the simulation.
