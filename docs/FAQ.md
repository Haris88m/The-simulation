# Frequently Asked Questions

## Is this claiming to predict the future?

No. The current prototype demonstrates simulation mechanics. A forecast track will only make calibrated public claims after empirical testing against declared baselines.

## Are the simulated worlds literal parallel universes?

No. They are sampled trajectories used to represent uncertainty and counterfactual consequences.

## Can a player propose anything?

Yes. Any premise may be simulated. The system records its provenance and does not automatically label it as observed reality.

## Can one player change every other player's world?

Not merely by asserting something. Verified evidence updates the shared baseline. Player premises affect personal branches, published branches, or consensually merged worlds according to permissions.

## Must players use ChatGPT or Claude?

No. Any hosted AI, local model, custom agent, browser, or direct API client may use the open protocol.

## Does the AI make the calculations?

No. The authoritative server performs the calculations and signs results. The AI interprets, questions, and proposes structured actions.

## Is the project open source?

The public explanation and protocol discussion are public. The implementation remains private during the security and scientific qualification stage. Licensing has not been finalized.

## Is there a live game now?

Not yet. The page includes a local protocol demonstration only. It does not create a real server node or persistent world.
