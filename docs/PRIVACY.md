# Privacy and Player Control

## Pseudonymous by default

The game should not require a legal name, address, political affiliation, religion, health information, or other sensitive profile data. A player receives a pseudonymous node and private credentials.

## Branch visibility

A world may be:

- private;
- shared by explicit link;
- published;
- merged only after consent from required owners.

## AI portability

The player's model provider does not own the world. A node can synchronize through another client without transferring the entire private conversation history.

## Data minimization

The server stores the structured action necessary for the simulation and an auditable source statement where required. Production design must define retention, export, deletion, recovery, and disclosure rules before public launch.
