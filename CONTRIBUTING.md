# Contributing

This repository is the public documentation and research-discussion surface for **The Simulation**.

Useful contributions include:

- identifying ambiguous or misleading claims;
- suggesting stronger scientific validation methods;
- improving accessibility and terminology;
- proposing protocol interoperability tests;
- identifying privacy or transparency weaknesses;
- adding references to relevant peer-reviewed research;
- reporting broken links or site defects.

Do not submit:

- credentials or API keys;
- private datasets or personal information;
- production secrets;
- unreviewed code copied from the private implementation;
- claims that a synthetic simulation output is established fact.

Open an issue with a concise problem statement, evidence, and proposed acceptance test.
